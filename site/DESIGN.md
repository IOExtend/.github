# Оформление IOExtend Web

Интерфейс наследует графитовый фон, яркие верхние грани и ступенчатую глубину из баннеров IOExtend, IOViewer, RvtIO и NwcIO. Графика опирается на геометрию BIM, а текст и элементы управления используют системный шрифт.

| Назначение | Цвет |
| --- | --- |
| Фон и рабочая поверхность | `#12161c` и `#191e27` |
| Основной и вторичный текст | `#edf3fa` и `#aebaca` |
| Просмотр и IOViewer | `#a5f3fc` |
| Экспорт | `#dbc0ff` |
| Понижение версии Revit | `#ffdc82` |
| Ошибки | `#ffc3ad` |

Акцент инструмента отмечает выбранную вкладку и основное действие. Светлая и тёмная грани кнопок повторяют логику пиксельной графики. На узком экране иллюстрация располагается под действием, а настройки экспорта переходят в одну колонку. Встроенный IOViewer получает ту же палитру панелей через `wwwroot/viewer-theme.js`.
